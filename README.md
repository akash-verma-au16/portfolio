# Akash Verma - Portfolio

Personal portfolio site built with React, TypeScript and Vite.

Live: https://akash-verma-au16.github.io/portfolio/

## Develop

```bash
npm install
npm run dev
```

Content lives in `src/data.ts`. Publish with `npm run deploy`, which builds and pushes `dist/` to the
`gh-pages` branch that GitHub Pages serves.
